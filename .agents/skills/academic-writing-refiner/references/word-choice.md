# Word Choice, Substitutions & Style Tables

This reference provides exact academic and scientific word substitutions to eliminate wordiness, pomposity, and AI cliché markers.

---

## 1. Simplify Overly Pompous or Fancy Words

| Pompous / Bloated Word | Recommended Clear Alternative |
|---|---|
| `utilize / utilization` | **use** |
| `demonstrate` (unless formal mathematical proof) | **show**, **indicate**, **reveal** |
| `elucidate` | **explain**, **clarify** |
| `a plethora of` | **many**, **numerous** |
| `a multitude of` | **many**, **various** |
| `subsequent to` | **after** |
| `prior to` | **before** |
| `in the event that` | **if** |
| `commence` | **start**, **begin** |
| `terminate` | **end**, **stop** |
| `facilitate` | **help**, **enable**, **promote** |
| `ameliorate` | **improve** |
| `ascertain` | **determine**, **find** |
| `manifested by` | **shown by**, **indicated by** |
| `leverage` (as verb) | **use**, **apply**, **exploit** |
| `synergistic effect` (when non-rigorous) | **combined effect**, **interaction** |
| `cornerstone / pillar` | **key factor**, **basis**, **foundation** |

---

## 2. Eliminate Redundant & Filler Phrases

| Wordy / Redundant Phrase | Lean Replacement |
|---|---|
| `in order to` | **to** |
| `due to the fact that` | **because**, **since** |
| `owing to the fact that` | **because** |
| `it is worth noting that` | *(delete completely)* |
| `it should be emphasized that` | *(delete completely)* |
| `it has been reported that` | *(cite source directly)* |
| `at this point in time` | **currently**, **now** |
| `for the purpose of` | **to**, **for** |
| `in the vicinity of` | **near**, **around**, **approximately** |
| `with the exception of` | **except** |
| `completely eliminate` | **eliminate** |
| `future plans / prospective plans` | **plans** |
| `consensus of opinion` | **consensus** |
| `first and foremost` | **first** |
| `a total of 45 patients` | **45 patients** |
| `during the course of the experiment` | **during the experiment** |
| `in a timely manner` | **promptly**, **rapidly** |

---

## 3. Calibrate Hedging and Certainty

| Weak / Over-Hedged Phrase | Calibrated Academic Formulation |
|---|---|
| `It could potentially possibly be argued that...` | **These findings suggest that...** |
| `There appears to be an indication that...` | **The data indicate that...** |
| `Might conceivably play a prospective role...` | **May contribute to...** |
| `Proves beyond doubt that...` *(Avoid over-claiming)* | **Demonstrates that... / Confirms that...** |
| `Obviously, the mechanism is...` *(Avoid condescension)* | **The mechanism involves...** |

---

## 4. Academic Connectives & Transition Signposts

| Logical Relationship | Recommended Transitions |
|---|---|
| **Contrast & Counter-argument** | *However, in contrast, conversely, nevertheless, whereas, on the other hand* |
| **Causation & Consequence** | *Therefore, consequently, as a result, thus, accordingly* |
| **Elaboration & Specificity** | *Specifically, in particular, namely, that is* |
| **Addition & Corroboration** | *Additionally, furthermore, in addition, moreover, similarly* |
| **Conditionality & Concession** | *Although, despite, while, even though, granted that* |

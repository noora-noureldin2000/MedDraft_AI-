# Reference Verification Log

One row per candidate source, filled during the search-and-verify phase (before drafting). No number may enter a draft without a completed row. Attach the completed log (or its summary) to the delivery as the verification notes.

## Log template

```
Ref #:
Citation (as it will appear in the reference list):
Design / N / population / setting:
Stance: supporting / contrasting / mixed / mechanism / guideline-review
Full text verified: Yes / No        (If No → exclude; note "I cannot verify full-text access.")
Access date:

Numbers extracted (each must map to a location):
  Metric 1 = value (p = ...) → location: [table/figure/page/section]
  Metric 2 = ...
Fields checked against source page: authors [ ] title [ ] journal [ ] year [ ] volume [ ] issue [ ] pages [ ] DOI [ ]
Unverified fields: [list, or "none"]
```

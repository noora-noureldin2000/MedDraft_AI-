## 2) Global Formatting — Applies to Entire Document (p.123 + checklist pp.123-129)

Enforce these on every page unless a component-specific rule overrides:

- **Margins:** Left `2.5 cm`, Right `1.5 cm`, uniformly throughout. Top: `5 cm` on FIRST page of every major component (Title, Abstract, Dedication, Acknowledgements, TOC, each chapter start, English/Arabic Summary, Recommendations); subsequent pages of that component: `2.5 cm`. Bottom: page numbers centered `1.5 cm` from bottom edge. For Appendices heading: `2.5 cm` top (or `1"` per p.120). For Lists: checklist says `2.5 cm` (body text p.115 says `1.5 cm` for Lists — prefer checklist `2.5 cm` but accept `1.5 cm` and note discrepancy).
- **Font:** `12 pt` throughout, single consistent typeface. Titles/headings are bold. Do not mix sizes except Title Page title `16 pt` and name `14 pt` (see §3.1).
- **Paragraphs:** Indented consistently throughout. Single column per page.
- **Spacing:** Body text `double-spaced` and `left-justified` (not centered, not fully justified). Exceptions `single-spaced`: block quotations, notes/footnotes, captions, legends, long headings that wrap to 2 lines, references within an entry, entry wrapping lines in TOC/Lists.
- **Pagination:** All page numbers centered at bottom, `1.5 cm` from bottom edge. Prelims (Copyright → Lists) = `lower-case Roman numerals` (`ii, iii, iv, v...`). Body (Introduction → Arabic Title Page) = `Arabic numerals` consecutive. Title Page counts as `i` but displays NO number. No running headers/footers except page numbers. Landscape pages need special spacing to keep number placement consistent.
- **Tables/Figures/Illustrations:** Uniform style throughout, Arabic numerals, headings/captions on SAME page as element, never orphaned.
- **Orphan control:** Sections/subheadings must not be left “hanging” at bottom of page alone.
- **Units note:** Guide mixes `cm` and `"` — `5 cm ≈ 2"`, `2.5 cm ≈ 1"`, `1.5 cm ≈ 0.6"`. When guide says `2"` use `5 cm`; when `1"` use `2.5 cm`. Preserve exact string from guide in comments.

## 3) Per-Component Detailed Rules

### 3.1 Title Page (p.111 + checklist p.124)

- Top margin `5 cm`.
- All elements **centered**, in this exact order:
  1. **Thesis Title** — ALL IN BOLD CAPITAL LETTERS, font `16 pt`, placed `5 cm` below top.
  2. **Submission statement** — verbatim, ending with period:  
     `"A thesis submitted to the Faculty of Dentistry at Cairo University in partial fulfillment of the requirements for the degree of [insert degree] in the [insert program name]."`  
     Fill brackets with actual degree/program.
  3. **Your name + degree** — bold block letters, `14 pt`, centered. Does not need to match university records exactly but recommend future publication name.
  4. **Faculty and name of university** — centered (e.g., `Faculty of Dentistry, Cairo University`).
  5. **Year** — centered, `one single-spaced line` below faculty line; year committee approves completed thesis (e.g., `2024`).
- Title must accord with Aim and must be **identical** to protocol title in Appendices.
- Pagination: counts as `i`, no printed number.

### 3.2 Copyright Page (p.111-112 + checklist p.124)

- Immediately follows Title Page.
- Text **single-spaced, centered, `5 cm` above bottom** of page:
  ```
  ©Year
  Author's Full Name (as it appears on title page) ALL
  RIGHTS RESERVED
  ```
  Year = approval year. Name must match Title Page exactly. `ALL RIGHTS RESERVED` on next line.
- Page number: `ii` lower-case Roman, centered `1.5 cm` from bottom. Protects authorship without filing.
- Checklist confirms: copyright symbol + year + exact name + ALL RIGHTS RESERVED + centered single-spaced 5cm from bottom + numbered `ii`.

### 3.3 Supervisors' Approval Page (p.112)

- Certifies supervisors' approval **before** thesis discussion.
- Order/layout per p.31 of guide (not in excerpt — preserve placeholder and ask user for template if missing). Must include supervisors' names, positions, signatures, date. Keep Roman pagination consecutive.

### 3.4 Jury Committee Approval Page (p.112)

- Certifies jury members' approval **after** thesis discussion.
- Order/layout per p.32 of guide. Include jury names, positions, signatures, date.

### 3.5 Declaration (p.112)

- Declare work is original and has not been used for award of any other degree.
- If any thesis work was published before final submission, **list those publications in References** to avoid self-plagiarism; clearly identify extent of your own contribution vs co-authors.
- No heading formatting specified — use standard chapter heading style if heading needed, else plain declaration text. Keep Roman pagination.

### 3.6 Abstract (pp.112-113 + checklist pp.124-125)

- Heading: `ABSTRACT` — bold capital letters, centered `5 cm` below top. Second page (if any) top margin `2.5 cm`.
- One **double-spaced line** below `ABSTRACT`, center: `Your Name: Title of thesis.` — as many lines as needed, name + title must **exactly match Title Page**. Title verbatim.
- One **single-spaced line** below title, center: `(Under the supervision of [supervisor's name])` — supervisor's name ONLY, no titles (`Dr.`, `Prof.`, `PhD`, `Head`). Parentheses required. Do not include other committee members.
- Skip **one double-spaced line**, then abstract text: **double-spaced, left-aligned**, indent new paragraphs, no centering/right-justify.
- Length: **150–350 words** (checklist says 150 for thesis, 350 for dissertation — enforce 150–350; flag <150 or >350 as BLOCKING).
- Numbered `iii` (and `iv` if second page), centered `1.5 cm` from bottom, lower-case Roman.
- Content: No symbols/foreign words when possible (not indexable), no formulas/diagrams/illustrations, no citations. Must be brief description + concise conclusions. Structure into labeled or paragraph sections answering:
  a. **Aim:** Why did you do it? Question answered?
  b. **Methodology:** How did you do it? Methods stated.
  c. **Results:** What did you learn? Major results.
  d. **Conclusions:** Why does it matter? At least one significant implication, 1–2 lines.
- Agent: When generating abstract, produce 4 paragraphs/sections covering a-d, count words, enforce 150–350, and validate heading margins.

### 3.7 Dedication (p.113 + checklist p.125)

- Optional. If present: **no heading** on page.
- Text: short tribute beginning `To ...` (e.g., `To my family`). Must be **centered**, beginning `5 cm` from top (checklist says `2"` — same as 5cm).
- Pagination: consecutive lower-case Roman starting after Abstract (e.g., `iv` or `v`), centered 1.5cm bottom.
- Each dedication starts on new page; if short, keep centered.

### 3.8 Acknowledgements (p.114 + checklist p.125)

- Heading **required**: `ACKNOWLEDGEMENTS` — all bold caps, centered `5 cm` (guide text says `5 cm`, checklist says `2"` — treat as 5cm) below top. Subsequent pages top margin `2.5 cm` (or `1.5 cm` per p.114 — note but enforce `2.5 cm` per checklist).
- Text begins **one double-spaced line below heading**, double-spaced, left-aligned, indent new paragraphs.
- Must acknowledge: (a) technical help (materials, supplies), (b) intellectual (assistance, advice), (c) financial (departmental support, grants, scholarships, funding org).
- Pagination: consecutive Roman after Dedication/Abstract, centered 1.5cm bottom.
- Starts on new page.

### 3.9 Table of Contents (pp.114-115 + checklist pp.125-126)

- Heading: `TABLE OF CONTENTS` — all bold caps, centered `5 cm` below top (first page); second+ pages `2.5 cm` top.
- One double-spaced line between heading and first entry.
- **Do NOT list** pages that precede TOC. **Must list** all parts that follow (chapters, Lists if present, Appendices, References) **with page numbers** but **no separate chapter numbers** for Appendices/References.
- Entries: aligned with left margin or indented consistently via tabs. Major subheadings within chapters MUST be included, indented right of left margin via consistent tabs.
- Wrapping: if entry >1 line, break about **one-fourth** across page (checklist says three-fourths — discrepancy; enforce one-fourth per body text, flag both as acceptable but prefer body spec), place rest on second line **single-spaced** between the two lines.
- Between entries: **one double-spaced line**.
- Page numbers: just inside right margin with **leaders (lines of periods)** filling space between entry end and number; last digit lines up on right margin.
- Content must **exactly match** headings/major subheadings/numbering in body.
- Pagination: consecutive Roman, centered 1.5cm bottom.

### 3.10 Lists of Tables & Figures (p.115 + checklist pp.126-127)

- Separate lists (or combined if preferred) — each on new page.
- Heading: `LIST OF TABLES` / `LIST OF FIGURES` — all bold caps, centered `1.5 cm` below top per body text, but checklist says `2.5 cm` — enforce `2.5 cm`, note discrepancy.
- One double-spaced line between heading and first entry.
- Each entry: **number, title, page number**. All tables/figures assigned **Arabic numerals**.
- Alignment: numbers/titles aligned with left margin or indented right via consistent tabs.
- Wrapping: break about **three-fourths** across page, rest on second line single-spaced.
- Between entries: **one double-spaced line**; entries themselves single-spaced if wrapping.
- Leaders: periods filling space to page number; last digit aligned on right margin.
- Numbers/titles/page numbers must match body exactly.
- Pagination: consecutive Roman, centered 1.5cm bottom.

### 3.11 List of Abbreviations & Symbols (pp.115-116 + checklist p.127)

- Include only if abbreviations/symbols used extensively.
- Heading: `LIST OF ABBREVIATIONS` (or `LIST OF ABBREVIATIONS AND SYMBOLS` if combined) — all bold caps, centered `1.5 cm` (checklist says `1"` = 2.5cm — enforce `1.5 cm` per body, note both) below top.
- One double-spaced line between heading and first entry.
- Abbreviations **alphabetically ordered**. Symbols listed **by appearance in text** (not alphabetically).
- Alignment: left margin or indented right via consistent tabs.
- Wrapping: single-space between lines of same entry.
- Between entries: **one double-spaced line**.
- Pagination: consecutive Roman, centered 1.5cm bottom.

### 3.12 Introduction (p.116 + checklist pp.127-128)

- Heading: `INTRODUCTION` — all bold caps, centered `2" (≈5 cm)` below top (note: body says 2" for Introduction/Discussion/Conclusions specifically, not 5cm — enforce `2"` as written).
- Content structure:
  1. First **two paragraphs**: general overview of what thesis is about + **hook** (interesting/important scientific problem your study solves/addresses to motivate reader).
  2. Show topic is worth investigating + significance, referencing existing research, identifying unexplored gaps / need for further exploration / new findings justifying reconsideration.
  3. Next paragraphs: cite most significant related research — who had idea first + most recent/relevant work, then explain why more work was necessary (your work).
- **Tense rules (strict):**
  - **Simple present** for: (i) your objectives, (ii) literature already known, (iii) generally true facts unlikely to change, (iv) past research results you believe true & relevant.
  - **Simple past** for: (i) facts once believed true but since revoked, (ii) methods of previous studies.
- Agent: When generating Introduction, verify hook in first paragraph, apply tense rules sentence-by-sentence, bold heading centered correctly, double-spaced left-justified.

### 3.13 Review of Literature (pp.116-117)

- Heading: `REVIEW OF LITERATURE` — all bold caps, centered `5 cm` below top.
- Purpose: describe/analyze previous research, **not** merely stringing findings. Discuss/analyze body of knowledge to determine what is known/unknown → leads to research questions/hypotheses. May note replication need.
- End with **synthesis paragraph** summing analysis + importance of your work.
- **Tense rules:**
  - **Simple past** when presenting existing research.
  - **Present tense** to share your own views about study in question.
  - **Present perfect** to cite fairly recent study (`Recent studies have shown that...`) or generalize past research (`Several researchers have studied...`).
- Body checklist: first page of chapter `5 cm` top, subsequent pages `2.5 cm`, double-spaced left-justified, consecutive Arabic pagination.

### 3.14 Aim of the Study (p.117)

- Heading: `AIM OF THE STUDY` — all bold caps, centered `5 cm` below top.
- Clearly state purpose + significance; without clear purpose/strong theoretical grounding thesis is fundamentally flawed.
- May state hypothesis from protocol verbatim.
- Tense: follow Introduction rules (present for objectives). Keep concise, direct.

### 3.15 Material and Methods (pp.117-118)

- Heading: `MATERIAL & METHODS` — all bold caps, centered `5 cm` below top.
- Must include:
  a. Complete description of **all materials** used.
  b. **Full detail of every step** of data gathering & analysis (believability + replicability).
  c. **Approved sample size calculation** by Medical Biostatistics Unit (MBU).
  d. **PICO** from registered protocol.
- Typically address: (a) limitations, calculations, assumptions, range of validity; (b) population + sampling justification/method for selecting units; (c) instrument/method development (question guide, content analysis categories) + pre-test reliability/validity; (d) administration (interviews, observation, content analysis); (e) coding of data; (f) statistical analysis/tests + reference to specialized software.
- **Tense:**
  - **Simple past** for what you did/how you did it (already completed).
  - **Past perfect** for earlier stages of experimental procedure (`Subjects who had been assigned to control group were given...`).
- Agent: Verify MBU approval and PICO are present; flag missing as BLOCKING. Detail must allow replication.

### 3.16 Results (pp.118-119)

- Heading: `RESULTS` — all bold caps, centered `5 cm` below top (guide has typo `RE SUL TS` — correct to `RESULTS`).
- Content: actual observations including statistics, tables, figures, graphs. **Only** data analysis results — no literature discussion or implication.
- Order: (1) descriptive/exploratory/confirmatory analyses (reliability, factor analysis), (2) hypothesis test results.
- Tables/figures: used to illustrate/summarize all numeric info, uniform style, numbered (Arabic).
- Include major findings + **negative results** equally; do not interpret (save for Discussion); indicate range of variation.
- Structure: break into logical segments via **subheadings**; key results stated in **clear sentences at beginning of paragraphs** — prefer `X had significant positive relationship with Y (linear regression p<0.01)` over vague `There is a significant relationship...`; describe nature of findings.
- **Tense:**
  - **Past tense** to describe completed experiments.
  - **Present tense** to refer to tables/figures/graphs (`Figure 3 shows that...`).
- Formatting: double-spaced left-justified; table/figure headings same page as element.

### 3.17 Discussion (p.119)

- Heading: `DISCUSSION` — all bold caps, centered `2"` (≈5 cm) below top.
- Purpose: discuss what findings **mean** re theoretical body of knowledge & profession — answers `So what?` — most important section.
- Structure:
  1. Few sentences summarizing **most important results**.
  2. Findings vs theoretical framework from literature review; may introduce new literature (esp. qualitative).
  3. Description of chosen method + why most appropriate, citing method literature.
  4. **Brief essay** answering:
     a. Major patterns & relationships?
     b. Likely causes/mechanisms?
     c. Agreement/disagreement with previous work?
     d. Relationship to original question (aim)?
     e. What is now known that was unknown before?
     f. Significance of present results?
  5. Evidence/line of reasoning to support each interpretation.
  6. **Future research** areas proposed.
  7. Brief conclusion providing closure + **strong final sentence**.
- **Tense:**
  - **Past** to summarize findings.
  - **Present** to interpret results/discuss significance/present conclusions.
  - **Future** to recommend further research / future course of action.
- Agent: Ensure Discussion does not merely repeat Results; enforce 6-question coverage, method justification with citations.

### 3.18 Conclusions (p.120)

- Heading: `CONCLUSIONS` — all bold caps, centered `2"` below top.
- Present **major conclusions** revealed, highlighting significance, **based ONLY on actual results** in thesis.
- Must answer question(s) raised in Introduction & Aim.
- Must be justified in preceding Discussion (no new data).
- Concise, direct.

### 3.19 Recommendations (p.120)

- Heading: `RECOMMENDATIONS` — all bold caps, centered `5 cm` below top.
- Optional but if present: based on Conclusions, refer to **further studies** to be followed based on present work.
- Use **future tense** where appropriate.

### 3.20 Appendices (pp.120-121 + checklist p.128)

- Must appear **after last chapter (before References)** — not after chapter they pertain to. Checklist p.128 says after last chapter before references — enforce this, even though p.110 order lists Appendices before References (consistent).
- Each appendix assigned number/letter: `APPENDIX 1` or `APPENDIX A` + descriptive title. Alternative: two-part Arabic numeral `APPENDIX 3.2` (second appendix in Chapter Three). Number consecutively throughout or by chapter — be consistent.
- Heading: all caps, centered `1"` (≈2.5 cm) below top (body) / `2.5 cm` per checklist — enforce `1"`.
- All appendix headings/titles **must be in TOC**.
- Page numbering continues consecutively (Arabic) with margin/pagination compliance.
- **Mandatory contents:**
  - Registered **Proposal / Protocol** (identical title)
  - **MBU sample size approval**
  - **Ethical Committee approval** (Human or Animal)
  - Signed **Thesis Submission Checklist**
- Agent: Flag missing mandatory appendix items as BLOCKING.

### 3.21 References (pp.121-122 + checklist pp.128-129)

- Begin on **separate page** after Appendices (or at end of entire document per checklist).
- Heading: `REFERENCES` (or `BIBLIOGRAPHY` / `WORKS CITED`) — all caps, centered at top, `2.5 cm` top margin.
- **Spacing:** Single-spaced **within** each entry, **one double-spaced line between** entries.
- Page numbering continues (Arabic).
- **Alphabetical order** by first author last name.
- **Format — exact (Vancouver-like but alphabetical):**
  - **Journal:** Last names + initials of **ALL authors** (et al. UNACCEPTABLE in reference list), year in parentheses, full paper title, abbreviated journal title, volume number, first page (or first & last pages).
    `Smith, A.B. and Jones, C.D. (1998): The structure of the human tooth. J. Dent. Res., 67: 22-25.`
  - **Book:** Last names + initials of ALL authors, year, full book title, edition number (except 1st), page(s) quoted, publisher, city/cities.
    `Smith, A.B. and Jones, C.D. (1998): Dental Histology, 2nd ed., p. 225, Blackwell Scientific Publications, London, Edinburgh, Melbourne.`
  - Multiple papers same author(s): **chronological** order; same year add letter `a, b, ...` after year in text AND list.
- In-text citations must correspond to alphabetical list with same letter suffix.
- Agent: Validate every entry is single-spaced internally, double between, alphabetical, no et al., correct punctuation per examples. Use reference manager style matching examples if automating (EndNote style that matches).

### 3.22 English Summary (pp.121-122)

- Heading: `ENGLISH SUMMARY` — all bold caps, centered `5 cm` below top.
- Written in **paragraphs**, somewhat simple language, strict sequential order:
  a. Main objectives
  b. Methods used
  c. Summary of results
  d. Primary conclusions
- Pagination: consecutive Arabic, first page 5cm top, subsequent 2.5cm, double-spaced left-justified.
- Agent: Ensure order a→d, no new material beyond body, concise.

### 3.23 Arabic Summary (p.122)

- Heading: `ARABIC SUMMARY` — all bold caps, centered `5 cm` below top.
- Must be **identical translation** of English Summary (content parity enforced).
- Arabic language text, right-to-left formatting.
- Pagination: consecutive Arabic.

### 3.24 Supervisor's Page in Arabic (p.122)

- Identical to English Supervisors' page but in Arabic: supervisor names, positions, signatures.
- Placement: **facing opposite English** such that reader opens from **right side** of thesis (book binding). Mirror layout.
- Required.

### 3.25 Title Page in Arabic (p.122)

- Identical translated Title Page in Arabic — title, submission statement (Arabic equivalent), author name/degree, faculty/university, year — must match English/protocol title.
- Placement: **facing opposite English**, opens from right side.
- Required.

## 4) Footnotes (p.128)

- Placed at bottom of page, separated from text by solid line `2.5–5 cm` long.
- Begin at left page margin, **one single-spaced line below** solid line.
- Longer notes: single-spaced between lines; **one double-spaced line between notes**.
- Numbered with **Arabic numerals** consecutively **within each chapter** (restart at 1 per chapter) OR consecutively through entire document — pick one and be consistent.
- Number is **superscript**, no space between number and note text.

## 6) Agent Workflow for User Demands

**Trigger phrases:** `thesis`, `dissertation`, `format my thesis`, `generate abstract/introduction/chapter`, `TOC`, `references`, `check my thesis`, `convert to Word`, `Arabic summary`, any file ending `.docx/.pdf` that is a thesis.

**Steps — always:**

1. **Read before write:** Read the target file (`thesis.docx`, `thesis.pdf`, `chapter*.docx`), one neighbor file, and this skill. Detect current component(s) and pagination state.
2. **Identify order position:** Map user request to §1 order. If generating a chapter, confirm its neighbors and pagination (Roman vs Arabic).
3. **Apply §2 global formatting** + §3 per-component rules verbatim. For generation, produce content that also follows tense rules and required content points (e.g., Introduction hook + gaps, Discussion 6 questions).
4. **Handle units & discrepancies:** Prefer body text measurements over checklist where they conflict, but always note discrepancy in output. Convert `"` to `cm` as `2" = 5cm`, `1" = 2.5cm`.
5. **References:** Enforce §3.21 style exactly; reject `et al.` in list; ensure alphabetical + chronological + letter suffix logic.
6. **Appendices/Approvals:** If user requests full thesis, demand or placeholder MBU/Ethical/Proposal/Checklist if not provided — flag missing as BLOCKING rather than silently omitting.
7. **Arabic pages:** When generating Arabic Summary/Supervisor/Title pages, ensure mirrored facing layout note and RTL text, and verify translation parity.
8. **Self-check before delivery:** Walk §5 checklist, fix every violation you can, list fixes as `component — what changed`. If you cannot fix (missing approvals, missing data), flag for author with reason.
9. **Output:** Deliver formatted file (or diff) + validation table + `thesis-master-guide: ...` closing line. For Word generation, set margins, font, spacing, pagination, heading styles programmatically (python-docx: `section.left_margin = Cm(2.5)`, `section.right_margin = Cm(1.5)`, `paragraph.paragraph_format.space_after`, `font.size = Pt(12)`, `font.bold`, `alignment = WD_ALIGN_PARAGRAPH.CENTER/LEFT`, `section.footer.paragraphs[0].alignment = CENTER` with `1.5cm` bottom via `section.footer_distance`).
10. **Preserve behavior when refactoring:** If user asks to “clean up / reformat” existing thesis, do NOT change content meaning, data, or citations — only formatting. Flag content bugs separately and ask before fixing.

**Generation templates:** When user asks to generate a chapter without providing content, ask for: topic/title, PICO, sample size/MBU details, methods, results data, key references. If they insist on drafting from scratch, generate plausible structured placeholder with `TODO: author to replace` markers and flag as draft.

**Language:** Default to English except Arabic Summary/Title/Supervisor pages which must be Arabic. Do not mix.

## 8) Common Failures to Catch (LLM-specific)

- Forgetting Title counts as `i` with no printed number → causes Roman offset by one.
- Using `et al.` in References list (forbidden) — list ALL authors.
- Centering body text instead of left-aligning (only headings/title elements are centered).
- Single-spacing body or double-spacing reference entry internals (reverse).
- Using present tense where past is required (Methods/Results) or vice versa (Introduction known facts).
- Placing Appendices after References (must be before).
- Omitting leaders (......) in TOC/Lists or misaligning last digit.
- Missing mandatory appendix items (Proposal, MBU, Ethical, Checklist).
- Generating Arabic summary not identical to English.
- Dropping signatures/approval pages or leaving English-only when Arabic facing pages required.

# Word Choice, Common Mistakes, and Transition Bank

|---|---|---|
| utilize, leverage | use | Almost never better than "use" |
| elucidate | explain | Keep it simple |
| demonstrate (loosely) | show | Reserve "demonstrate" for formal proof/demonstration |
| a plethora of, a myriad of | many | |
| completely eliminate | eliminate | |
| future plans | plans | |
| due to the fact that | because | |
| in order to | to | |

## Banned AI-signature vocabulary

Never introduce: delve, crucial, tapestry, multifaceted, nuanced, groundbreaking, paramount, "a myriad of", "it is worth noting that", leverage, pivotal, foster, harness, testament, commendable, "landscape" (figurative). Limit "robust" (max once per document) and "underscore" (max 2–3 uses).

## Punctuation discipline

No em-dashes used liberally (at most one pair per paragraph; parentheses or restructured sentences are usually cleaner). No long semicolon-connected chains; prefer shorter sentences joined by appropriate connectives.

## Transition bank (choose by function, vary placement)

- Addition: furthermore, moreover, similarly, in addition, in parallel, also
- Contrast: however, nevertheless, conversely, in contrast, on the other hand
- Cause-effect: therefore, consequently, thus, accordingly, as a result
- Sequence: first, second, subsequently, finally
- Example: for example, for instance
- Emphasis and framing: notably, strikingly, consistent with, against this backdrop, in parallel
- Conclusion: in conclusion, in summary, taken together, collectively

Never open consecutive paragraphs with the same transition, and do not start every paragraph with a transition at all.
